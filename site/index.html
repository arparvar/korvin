Honest setup requirements

One command installs everything.

SSH into any Ubuntu or Debian VPS once. You need a Telegram bot token and a Gemini or DeepSeek API key. The installer sets up all services automatically.

curl -fsSL https://raw.githubusercontent.com/nosistech/korvin/main/install.sh | sudo bash

Start with API keys. Once running, swap in any LiteLLM-compatible model — including local Ollama — by editing one config file. No code changes, no rebuilds.

Optional upgrades after install.

Korvin runs fully out of the box. These options are available when you need more.

STT quality upgrade

distil-large-v3

Switch from tiny.en to distil-large-v3 for significantly higher transcription accuracy. Set in the dashboard under Voice settings. Requires 4 GB+ RAM — not suitable for a $5 VPS.

Korvin routes through LiteLLM. Swap in Claude, GPT-4o, Mistral, or a local Ollama model by editing one config file. No code changes. Switch back in the dashboard.

Skills

Six skills. Unlimited ways to use them.

Every skill works through Telegram chat — just describe what you need. New skills can be added without touching the core.

Research [topic] Web Research

Searches the web via DuckDuckGo and synthesizes a structured report with key findings and sources. No API key required — runs entirely through Korvin.

Try it

  • "Research the latest PostgreSQL 17 features"
  • "Research competitors to my SaaS idea: [describe it]"
  • "Research side effects of [medication] and summarize in plain English"
every [schedule] do [action] Task Scheduling

Creates cron jobs that run automatically and message you the result. Supports daily, hourly, weekly, and day-of-week schedules.

Try it

  • "Every morning remind me to review my priorities"
  • "Every Monday research the top AI news from the past week"
  • "Remind me to drink water every 2 hours"
write a [type] about [topic] Document Drafting

Generates structured documents — proposals, reports, emails, SOPs, job descriptions. Output includes section headers and placeholder fields ready to fill in.

Try it

  • "Write a proposal about migrating our app to a VPS"
  • "Draft a client email explaining a two-week delay"
  • "Write a job posting for a backend developer with Go experience"
/security Security Monitor

Runs a live VPS health report: CPU, RAM, disk, uptime, and status of all Korvin services. Detects and reports anomalies in seconds.

Try it

  • "/security" — instant health snapshot
  • "every morning run /security" — daily automated health digest
  • After a deploy: run /security to confirm all services restarted cleanly
/scan deps Dependency Scan

Reads package.json and requirements.txt and reports dependency metadata — names, versions, and known issues. Zero-execution: never invokes npm, pip, or any package manager.

Try it

  • "/scan deps" — full dependency report
  • Run before a production deploy to catch stale or flagged packages
  • Schedule weekly: "every Monday run /scan deps"
/youtube [url] YouTube Transcription

Transcribes any YouTube video and returns the full text. Paste a YouTube URL in chat and Korvin handles it automatically — no need for the /youtube prefix.

Try it

  • Paste a YouTube URL and ask "summarize this"
  • "Transcribe this lecture and pull out the key points: [url]"
  • Research a topic then transcribe a related video for deeper context

Custom skills

Build your own skill in two files.

Korvin ships with a plugin system. Drop a directory into skills/, define a trigger regex, and Korvin auto-loads it on the next restart — no changes to the core required.

How it works

Each skill is a directory with two files: a skill.json manifest and a handler.js module. The manifest defines the trigger pattern and permission level. The handler receives the matched message and returns a string response.

  • No registration needed — auto-discovered at startup
  • Three permission levels: read-only, network-read, local-status
  • Path traversal blocked — handler must stay inside skill directory
  • Errors are caught and reported — bad handlers don't crash the agent
// skills/my-skill/skill.json
{
  "name": "my-skill",
  "description": "What this skill does",
  "trigger": "^my trigger (.+)",
  "permission": "read-only",
  "handler": "./handler.js"
}

// skills/my-skill/handler.js
async function run(message, match) {
  return "You said: " + match[1];
}
module.exports = { run };
