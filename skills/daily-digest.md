# daily-digest

**Trigger:** Automatic — runs every night at 23:00 (server time)

**Action:**
1. Read the active chat ID from `data/security_monitor_chat.txt`.
2. Call `summarizeSession` with the active model to produce a short digest of the day's conversation.
3. Append the digest (first 200 characters) to `MEMORY.md` under today's date header.
4. Send the full digest to Telegram.

**Setup:** Activated automatically on bot start — no user action needed. Requires at least one `/scan` or security-monitor interaction to register the chat ID.

**Security:** No external requests. Digest is generated by the local LiteLLM proxy using whatever model is active.
